# Vite + Deno + React + TypeScript

## What is This?
A Browser extension  that skips the last X seconds of a youtube channel.This is aimed to skip those annoying youtube outros
## Running

You need to have Deno v2.0.0 or later installed to run this repo.

## Build

Build production assets:

```
$ deno task build
```
## Testing

Open chrome://extensions/ > Enable Developer mode > Load Unpacked and Open Project's root folder
